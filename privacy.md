# Privacy policy

Last updated: 2026-10-11

Chart Studio ("the app") is a private, non-commercial application used by one household. This policy describes what it stores when a user connects a Google or Spotify account.

## What the app stores

- The e-mail address of the connected Google account, to show which account is linked.
- OAuth access and refresh tokens for the connected account, stored encrypted, used only to perform the actions below.
- The identifiers and titles of YouTube playlists the app creates or updates in the connected account.
- Rows read from Google Sheets the connected user has explicitly chosen to import (song titles, artists and chart positions).
- Public music chart data and the user's own playlist contents from the connected streaming services.

## What the app does with Google user data

- Creates and reorders YouTube playlists in the connected user's own account, so that a playlist mirrors a chart the user tracks.
- Reads spreadsheets the user selected, to import a chart.
- Plays videos through the standard embedded YouTube player. Nothing is downloaded, copied or modified.

## What the app does not do

- It does not sell, share, publish or transfer Google user data to anyone.
- It does not use Google user data for advertising, profiling or training models.
- It does not store video content.
- It does not use Google user data for any purpose other than the features above.

## Retention and deletion

Data stays only while the account is connected. Disconnecting the account in the app's settings deletes the stored tokens. Any stored data can be deleted on request to the contact address below. Access can also be revoked at any time from the Google account's third-party access page, which immediately stops the app from acting on that account.

## YouTube API Services

The app uses YouTube API Services. By using the YouTube features you also agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms), and Google's handling of your data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

- Data obtained from YouTube API Services: video ids, titles, channel names, durations and thumbnail URLs for matched videos; the ids and titles of playlists the app creates or updates in your account.
- The app stores that data only to display matches and keep your playlists in sync; it is refreshed on each sync and never shared with third parties.
- Videos are played only through the embedded YouTube player; no video content is stored.
- You can revoke the app's access to your YouTube data at any time from the [Google security settings page](https://security.google.com/settings/security/permissions). Revoking access stops all syncing immediately; stored tokens and playlist records are deleted when you disconnect the account in the app or on request to the contact address below.

## Limited use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
